# Côte Noire — Royal Template

Version complète du template client.

## Fonctionnalités
- Design Côte Noire noir / espresso / beige / doré
- Sidebar avec Nouveauté, Fleurs, Bougies, Diffuseurs et Cadeaux
- Navbar avec recherche
- Catalogue connecté au backend
- Détails produit au clic
- Ajout au panier
- Affichage des articles du panier
- + / - pour modifier les quantités
- Suppression d'un article
- Respect du stock disponible
- Checkout
- Paiement à la livraison uniquement
- Livraison standard / express
- Backend conservé sur `http://localhost:8086`

## Installation

```bash
npm install
npm start
```

Frontend : `http://localhost:5173`

Pour changer le port frontend, modifier `server.port` dans `vite.config.ts`.
